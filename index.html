Good to know

Questions, answered.

A few details about how the service is intended to work.

How much space can I use?

The planned account limit is 1 GB total. A single file must be smaller than 100 MB.

What kinds of files can I upload?

The file space is intended for photos, videos, documents, audio, and other common personal files that fit within the per-file limit.

Can I access uploads from another device?

Yes, when you open the same hosted Docs Drive service and sign in with the same account. Files are stored on the application server rather than in the browser.

How are passwords and files handled?

Passwords are stored as salted hashes, and file requests are checked against the signed-in account. Use HTTPS and persistent server storage when deploying the site publicly.
